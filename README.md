# joeljanssen27.github.io

My personal website: https://joeljanssen.com

| File | What it is |
|---|---|
| `index.html` | All the text on the page. Comments inside show how to add a project, article, scouting report or photo. |
| `styles.css` | Colours, fonts and layout. Change `--accent` at the top to restyle the site. |
| `script.js` | Animations. |
| `images/` | Photos and logos. |
| `reports/report-template.html` | Copy this to write a new scouting report. |

To update the live site, edit the files and then run:

```
git add -A
git commit -m "What changed"
git push
```

The live page refreshes a minute or two after the push.
